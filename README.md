# 1-site

Исходный репозиторий: https://github.com/nnnuuurrriiikkkzh/1-site

## Запуск

1. Распакуйте архив целиком.
2. Откройте index.html в браузере. Обе исходные фотографии встроены в HTML и работают даже без отдельных файлов изображений. Файлы first.jpg и Игилик.jpeg также сохранены в проекте.
3. На главной странице выберите цвет текста и размер шрифта в пикселях (целое число от 1), затем нажмите «Изменить абзац». Можно применять новые настройки сколько угодно раз. Сам текст абзаца не является кнопкой.
4. Кнопка «Переключить active» добавляет или удаляет класс active у элемента второго задания. Надпись меняется на «Класс active добавлен» или «Класс active удалён».
5. Список классов отображается в отдельном p и в консоли браузера (F12 → Console).

## Открытие в Visual Studio Code

1. Загрузите VS Code: https://code.visualstudio.com/download
2. Выберите File → Open Folder и откройте папку 1-site.
3. Или выберите File → Open Workspace from File и откройте 1-site.code-workspace.
4. Весь код находится в index.html: HTML, CSS внутри style и JavaScript внутри script.

## Работа с DOM

- Текст элемента, найденного по ID, заменяется на «Сәлем, әлем!».
- В конец body добавляется div с классом new-div и текстом «Мен жаңа элементпін».
- Элемент с классом old-element удаляется.
- Создаётся p с текстом «Бұл ауыспалы абзац». Его оформление меняется отдельной кнопкой.
- Класс active переключается через classList.toggle; все классы выводятся на страницу и в консоль.
- Функция showTab сохранена без изменений.

## Подсказки в анкетах

Наведите курсор на профессию на главной странице или на карточку в любой анкете. Подсказки объясняют профессию, учёбу, город, работу, еду и увлечения. На телефоне нажмите на карточку; с клавиатуры используйте Tab и Enter. Повторное нажатие, Escape или нажатие вне карточки закрывает подсказку.

Описания используют сведения исходной анкеты и общие пояснения. Краткие подписи переведены на русский.
